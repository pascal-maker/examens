# Deep Learning Project

## Overview

This repository contains deep learning experiments and utilities developed by Pascal Maker. It includes model implementations, training scripts, and example notebooks.

## Setup

```bash
# Clone the repository
git clone https://github.com/pascal-maker/deeplearning.git
cd deeplearning

# (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

## Usage

- **Training**: Run `python train.py --config config.yaml` to start training a model.
- **Evaluation**: Use `python evaluate.py --model_path path/to/model.pt` to evaluate a trained model.
- **Notebooks**: Open the Jupyter notebooks in the `notebooks/` directory for interactive exploration.
