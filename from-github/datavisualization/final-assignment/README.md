# Final Assignment

This folder contains the final data visualization assignment deliverables.

## PedLabel

`pedlabel/` contains the UX brief, Figma prototype files, exported prototype archives, and supporting assignment documents for the PedLabel concept.

## Wire Prototype

`wire-prototype/` contains the source files for the wire prototype/plugin implementation:

- `manifest.json`
- `code.ts`
- TypeScript configuration
- ESLint configuration
- package metadata

The final assignment files are grouped here to keep them separate from the lab and API exercises in the rest of the repository.
